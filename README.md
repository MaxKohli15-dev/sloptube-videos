# SlopTube – Videos

Hier liegen alle Uploads für SlopTube.

```
DATUM/KANALNAME/VIDEONAME.mp4    ← Video
DATUM/KANALNAME/VIDEONAME.jpg    ← Vorschaubild (optional)
DATUM/KANALNAME/VIDEONAME.txt    ← Beschreibung (optional)
_kanaele/KANALNAME/avatar.jpg    ← Profilbild
_kanaele/KANALNAME/banner.jpg    ← Kanalbanner
_kanaele/KANALNAME/info.json     ← {"about": "Kanalbeschreibung", "links": ["https://..."]}
```

`index.json` wird nach jedem Upload automatisch von einer GitHub Action erstellt – nicht von Hand bearbeiten.
